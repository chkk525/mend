mend is one command-line tool that applies AI-written edits in four formats — unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of files, exactly to a written specification. It finds the lines an edit names even when the model drifted their whitespace or indentation, and changes every file or none.

## Run it

```sh
node main.ts [options] [PATCH]
```

Requires Node 22 and its standard library alone; nothing is installed before the program runs.
